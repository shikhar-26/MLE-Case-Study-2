# MLE-Case-Study-2

# Credit Card Fraud Detection using XGBoost, SMOTE and Threshold Tuning.
Goal: build a fraud detector on a heavily imbalanced dataset, fix the imbalance with SMOTE, train XGBoost, tune the decision threshold, look at feature importance, and generate a final submission CSV.> Dataset used here (`credit_card_transactions.csv`) is a small synthetic dataset (1000 rows, 8 columns) built to have the SAME kind of pattern as real fraud data (e.g. IEEE-CIS on Kaggle): very few fraud cases, and fraud transactions tend to be larger amount, odd hour, new account, far from home. Upload this CSV to Colab before running.
